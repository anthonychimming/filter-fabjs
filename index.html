Filter FabJS v2.9.3 — Help

Start in Explore to try filters and adjust their controls. Switch to Author when you want to edit formulas or save your own filter.

Get started

  1. Select Open image, drop an image onto the preview, or use Paste image. Large images are resized to a maximum of 1,800 pixels on their longest side.
  2. Select Open Filter Library, choose a filter to preview it on your image, then select Apply Filter.
  3. Adjust the controls in Explore and select Export PNG to download the filtered image with transparency.

Find and preview filters

The Filter Library includes Built-in, My Filters, and Online. Search by name, description, author, or tag. Use Favorites to find filters you have starred. When you select several tags, results must match all of them.

Selecting a filter previews it on the canvas. Apply Filter keeps your selection; Cancel or Escape restores the filter and adjustments you had before opening the library.

Online cards show Sample images; select a card to see its effect on your own image. Online filters need an internet connection to load. Applying one does not save it to My Filters: use Save Filter in Author to keep a local copy. Download PNG downloads a file containing the filter and its sample image. Marking an Online filter as a favorite does not download or save it. If loading fails, use Retry or select the failed preview again.

Adjust and try variations

Controls update the preview automatically. Disabled controls are not used by the current filter. Reset restores the filter's starting control values. Randomize tries new values; Mutate varies the current values at your chosen strength. Lock controls you want to keep unchanged during Randomize and Mutate. Undo reverses the last Explore action; it is not a history of every edit.

Use Snapshots A–D to compare control settings: choose Save current and a slot, then select that slot to recall it. Snapshots are temporary and are cleared when you load another filter. Save or export a filter to keep a result.

Compare the image

Choose Filtered, Original, or Split above the preview. In Split view, drag the divider to compare both images. Use Fit to fit the image on screen and + or − to zoom. The light checkerboard shows transparent areas. Preview mode and zoom do not change the exported image.

Save your filters

In Author, add a name, author, description, and tags, then select Save Filter to add the current filter to My Filters. Update Filter updates an existing saved filter. When a save dialog offers Save as New, it creates a separate copy. Rendering and exporting an image do not save a filter to My Filters.

My Filters, favorites, and personal tags are stored in this browser. They do not automatically transfer to another browser or device, and clearing browser data can remove them. Use Export filter to keep a JSON backup or share your filter.

Create or edit a filter

Author has one formula for each output channel: red, green, blue, and alpha (opacity). r, g, b, and a read the original image's channels. For example, 255-r in the red formula inverts red; a in the alpha formula preserves the source transparency. Final channel values are limited to 0–255; alpha 0 is transparent and 255 is fully opaque.

Formula edits are checked as you type. Fix any errors shown beneath a formula, then select Update Preview or press Ctrl/⌘ + Enter while editing a formula. Formula edits do not update the image automatically. Expand Formula quick reference in Author for available variables and functions.

Edit controls lets you name controls and choose sliders, number fields, toggles, or seed fields. Formulas read control slots 0–9 with ctl(i), which returns 0–255. Use val(i,min,max) to map a control to another range. If you change a control's display range, use the matching range in val().

Reset to Pass Through loads a filter that leaves the image unchanged. It keeps your source image but replaces the current filter edits.

Files

Import filter opens Filter FabJS JSON files and historic Filter Factory .afs files. Imported filters work on your current source image. AFS filters use legacy math and run on the CPU; some historic effects may differ from the original software. Export filter saves the current filter and settings as JSON.

Export PNG saves the filtered image with transparency and an embedded copy of the current filter. If you have edited formulas, update the preview before exporting. When you open or drop a PNG containing a filter, Apply Embedded Filter loads that filter while keeping your current source image; Open Image Only opens the PNG without applying its embedded filter. You can also cancel.

Other image editors or optimizers may remove the embedded filter. Clipboard image operations do not preserve it. Keep a JSON export when you need a separate filter backup.

Copy and paste images

Copy image copies the filtered image; Paste image loads an image from the clipboard. Clipboard access depends on browser support and permission. If a receiving app loses transparency, use Export PNG instead.

Rendering and troubleshooting

Leave the renderer on Auto for normal use. It uses GPU acceleration when available and falls back to the CPU when needed. The renderer status shows which is active. In Author, expand Technical diagnostics to choose Auto, GPU, or CPU and read any fallback reason. Choosing GPU still allows CPU fallback.

CPU and GPU results can differ slightly, especially around fractal edges. If an effect looks different with GPU enabled, try CPU. GPU and clipboard features work best over HTTPS or localhost; opening a standalone HTML file directly may limit these features.

While rendering, editing is temporarily locked. Press Escape to cancel. If rendering is too slow or reaches its work limit, try a smaller image or a simpler filter.
